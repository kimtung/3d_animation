# AI 3D Family Animation Engine – Character Prototype

## 1. Mục tiêu dự án

Tôi muốn xây dựng một **AI 3D Story Animation Engine** để sau này tự động tạo các bộ phim hoạt hình 3D ngắn về một gia đình 4 người:

* Bố
* Mẹ
* Con trai
* Con gái

Concept chính:

> Một gia đình hạnh phúc, các tình huống hài hước đến từ những chuyện đời thường. Mẹ khá nghiêm khắc và nguyên tắc, bố vui tính nhưng hơi lười và thường tìm cách né việc. Con trai thường đứng về phía bố. Con gái thông minh, tinh nghịch và đôi khi khiến tình huống trở nên hài hước hơn.

Ví dụ các episode trong tương lai:

* Bố trốn rửa bát.
* Bố lén ăn đồ ăn của con.
* Bố mua một món đồ mà mẹ không cho mua.
* Bố ngủ quên.
* Hai bố con tìm cách xem TV nhưng bị mẹ phát hiện.
* Con trai luôn bênh bố.
* Con gái vô tình "tố cáo" bố.
* Cả gia đình đi siêu thị.
* Bố sửa một món đồ và làm nó hỏng hơn.
* Mẹ giao việc nhà cho cả nhà.

Mục tiêu dài hạn là:

```text
User Prompt
    ↓
AI Story Generator
    ↓
Comedy Engine
    ↓
Story Graph
    ↓
Scene Planner
    ↓
Character Behavior
    ↓
Timeline
    ↓
Camera
    ↓
3D Runtime
    ↓
Render
    ↓
Video
```

Tuy nhiên, **hiện tại KHÔNG xây toàn bộ hệ thống này**.

Chúng ta bắt đầu bằng một **Character Prototype** thật tốt.

# 2. Mục tiêu của Character Prototype

Prototype đầu tiên chỉ cần một nhân vật:

## Dad

Dad phải là một **3D character có thể lập trình để diễn**, không phải chỉ là một model 3D đứng trong scene.

Prototype phải chứng minh được:

1. Load được 3D character.
2. Character có skeleton/rig.
3. Character có animation.
4. Character có state.
5. Character có behavior.
6. Character có thể di chuyển trong 3D scene.
7. Character có thể nhìn về một object.
8. Character có thể ngồi xuống.
9. Character có emotion cơ bản.
10. Character có thể nói một câu.
11. Camera có thể theo dõi character.
12. Có timeline để điều khiển sequence.
13. Kiến trúc đủ sạch để sau này thêm Mom, Son, Daughter mà không phải viết lại engine.

# 5. Character Architecture

Mỗi character phải có 3 lớp:

```text
Character
│
├── Identity
├── State
└── Behavior
```

## Identity

Thông tin ổn định:

```typescript
{
  id: "dad",
  name: "Dad",
  personality: [
    "funny",
    "kind",
    "slightly_lazy",
    "easy_going"
  ]
}
```

## State

Thông tin thay đổi trong runtime:

```typescript
{
  location: "living_room",
  mood: "happy",
  energy: 80,
  action: "sitting"
}
```

## Behavior

Các hành động mà character có thể thực hiện:

```text
idle
walk
sit

look_at

 ↓
WALKING

 ↓

 ↓

```

# 8. Behavior API

Tạo một API giống:

```typescript
dad.idle();

dad.walkTo(target);

dad.lookAt(target);

dad.sit();

dad.stand();

dad.say("Anh chỉ xem một chút thôi.");

dad.setEmotion("happy");
```

Behavior phải có khả năng chạy bất đồng bộ hoặc trả về Promise để có thể sequence:

```typescript
await dad.walkTo(sofa);
await dad.lookAt(tv);
await dad.sit();
await dad.say("Anh chỉ xem một chút thôi.");
```

Mục tiêu là sau này Story Engine có thể compile story thành các action như trên.

# 9. Motion Controller

Tách movement khỏi animation.

Ví dụ:

```text
walkTo(sofa)
    ↓
calculate direction
    ↓
rotate character
    ↓
move character
    ↓
play walk animation
    ↓
detect arrival
    ↓
stop movement
    ↓
play idle animation
```

Không hard-code tốc độ trong nhiều nơi.

Có config:

```typescript
movementConfig = {
  walkSpeed: ...,
  rotationSpeed: ...
}
```

Ví dụ:

 ↓

 ↓

Không để Behavior Manager trực tiếp thao tác quá nhiều với Three.js AnimationMixer.

# 15. Timeline Engine

Không muốn toàn bộ sequence nằm trong một function khổng lồ.

Tạo timeline abstraction.

Ví dụ:

```typescript
timeline.add({
  start: 0,
  action: () => dad.idle()
});

timeline.add({
  start: 1,
  action: () => dad.lookAt(tv)
});

timeline.add({
  start: 2,
  action: () => dad.walkTo(sofa)
});

timeline.add({
  start: 6,
  action: () => dad.sit()
});

timeline.add({
  start: 10,
  action: () =>
    dad.say("Anh chỉ xem một chút thôi.")
});
```

Hoặc tốt hơn nếu có thể thiết kế thành declarative format:

```json
{
  "timeline": [
    {
      "time": 0,
      "actor": "dad",
      "action": "idle"
    },
    {
      "time": 1,
      "actor": "dad",
      "action": "look_at",
      "target": "tv"
    },
    {
      "time": 2,
      "actor": "dad",
      "action": "walk_to",
      "target": "sofa"
    },
    {
      "time": 6,
      "actor": "dad",
      "action": "sit"
    }
  ]
}
```

Ưu tiên thiết kế để sau này AI có thể generate JSON tương tự.
